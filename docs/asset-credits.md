# Alpine visual reference and asset

The user's supplied image informs layout, spacing, palette and atmosphere. It
is not embedded as a flat UI screenshot. Branding follows the supplied written
directive: CARPATIA ULTIMATE EDITION 1.0.0.

The app's mountain photograph was downloaded from Unsplash:

https://images.unsplash.com/photo-1464822759023-fed622ff2c3b

License information: https://unsplash.com/license

This photograph keeps its Unsplash license and is excluded from the root MIT
grant. See `THIRD-PARTY-NOTICES.md` for the distinction between project code and
upstream assets/dependencies.

It is bundled at `src/Carpatia.Ultimate.App/Assets/alpine.jpg`; the app does not
fetch remote images. It is a visual alpine landscape, not a verified photograph
of a named Carpathian location. The stylized mountain emblem is original vector
geometry. UI icons use the Windows system icon font.

Review third-party asset and dependency notices before commercial distribution.
